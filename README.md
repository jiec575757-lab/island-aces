# 海岛飞行队 · ISLAND ACES v1.4.0

这次从保存的最初 **v1.0** 源码重新修改。保留原版海岛、云层、飞机切片与三视角，加入经验、升级三选一、17 种可叠加被动和精英空战。此前 v1.1 留在单独备份目录，本目录是重新制作后的版本。

在线游戏：[jiec575757-lab.github.io/island-aces](https://jiec575757-lab.github.io/island-aces/)。GitHub Pages 自动发布配置已包含在 `.github/workflows/pages.yml`，具体步骤见 [GitHub 发布说明](GitHub发布说明.md)。

## 启动

双击 `启动游戏.cmd`，或在本目录执行 `npm start`，访问 **http://127.0.0.1:4192/**。按 **C / 开始空战** 进入肉鸽模式。需要 Node.js，无需 npm install；页面和素材全部本地运行。

| 操作 | 电脑 | 触屏 / 手柄 |
| --- | --- | --- |
| 转向、升降 | 鼠标 / WASD / 方向键 | 左右倾斜手机、左倾 / 右倾按钮、拖动 / 左摇杆 |
| 加速 | 按住右键 / Shift | 右侧加速 / RT |
| 射击 | 自动开火 | 自动开火 |
| 翻滚 | 左键 / Q | 左侧翻滚 / A |
| 换视角 | 空格 | 视角 / Y |
| 三选一 | 点击卡片 / 1、2、3 | 点击卡片 |
| 空战 / 暂停 | C / P | 页面按钮 |
| 全屏 / 隐藏界面 | F / H | 页面按钮 |

空战自动开火、左键翻滚、右键加速。自由飞行保留原版短按左键翻滚、长按加速。默认反转升降：W / 上方向键下降，S / 下方向键爬升，设置可取消。

机炮只在有效敌人进入攻击距离和机头前方扇区时自动开火：基础距离约 700 米、左右各约 30°。没有目标、敌人位于侧后方、超出射程或已被击落时停火补弹；广域雷达升级继续扩大索敌距离。导弹、副炮、僚机保留各自索敌规则。

手机采用横屏：支持时请求浏览器锁定横屏，否则自动旋转游戏画面适配。点按开始空战时可授权倾斜转向，之后按“校准倾斜”重置中位；拒绝传感器权限仍可使用左右转向按钮。手机 UI 更小，场景镜头缩至原比例的 62%，渲染像素倍率也从默认 3 降为 2，可以看到更大范围。

## 这次修改

- v1.4：新增单位改为实心体素表面，具有方向光照、侧面与底面、完整俯仰和侧倾、逐像素深度遮挡。敌方战机沿用初版体积，精英增加装甲或挂载；基地增加立体堡垒、雷达塔和发射箱。
- 新增海狼快速炮艇、苍礁导弹护卫舰：只在海面生成、巡航和避岸，带尾流；炮艇使用防空炮，护卫舰增加追踪防空导弹，击毁给予更多经验。第二波保证尝试加入炮艇，三级起尝试加入护卫舰；没有合适海域时不强行生成。
- 友敌追踪导弹和自爆机超时后在最后位置爆炸；超时爆炸为视觉效果，不追加范围伤害。敌方机炮弹加大，使用深色外缘、橙色弹体、亮色弹芯与尾迹，伤害半径不变。
- 自动机炮基础射程从 460 米扩大到 700 米，机头扇区从左右各 13° 扩大到各 30°；无目标仍停火补弹。

- v1.3.1：有目标且在射程与前方角度内才自动开火，离开范围即停火，避免对空浪费弹药。
- v1.3：自动开火；左键翻滚、右键加速；无外框点阵 HUD 仅显示血量、弹药、等级与经验；手机横屏、倾斜与触屏转向、缩小界面与场景比例。
- 60 发机炮弹药，初始每秒补充 7 发；Q 初始无敌 0.45 秒、冷却 2.8 秒。碰撞、敌弹、死亡重开均实际计算。
- 开局 4 架敌机从四周朝玩家飞来；后续来敌按环形扇区分散，带不同进攻航线和近距离避让。
- 击杀经验与精英额外经验、升级暂停三选一、17 种重复升级的被动、敌人等级和数量同步增长。
- 防空炮基础单发 4 点、每 1.15 秒一发；防空导弹 7 点、每 7 秒一发。僚机基础单发 0.25，地面支援基础单发 0.4；机炮仍是主要输出。
- 导弹重新制作锥形弹头、弹体识别环、四片后掠尾翼和喷口，朝向随三维速度变化，带短尾喷焰与烟迹。
- 屏幕外敌人显示方向箭头，普通红色、精英金色、后方紫色。三种镜头均显示；雷达范围可升级。
- 空战转向和镜头跟随更快，采用平滑响应；保留原版镜头距离、构图、侧倾与自由飞行参数。

规则和数值见 [肉鸽玩法说明](肉鸽玩法说明.md)，来源和工具优点见 [制作说明](制作说明.md)。

## 素材与源码

- `src/scene.js`、`cockpit.js`、`flame-layer.js`：源自参考页公开运行时的场景、驾驶舱、尾焰，保留来源。
- `src/combat.js`、`upgrades.js`：战斗、经验和被动；`unit-models.js`：新增体素模型。
- `reference/`：示例公开源码、参数、预览图及来源记录。
- `models.html`：飞机切片检视和全部海空单位的可旋转立体预览，与游戏共用表面渲染器。
- `models/`：原机及 11 种海空单位的 `.vox` 和 JSON；`assets/`：原机 13 层切片、重建四视角 PNG。

原机为 34×46×13、2,564 体素。分享元数据中的原始 `jet-four-views.png` 下载地址未取得，现有原机模型均从公开运行时真实切片导出；没有将重建图冒充原画。

## 验证与导出

```powershell
npm test
npm run test:browser
npm run export:models
```

核心测试覆盖所有被动、实际命中、回复、碰撞、死亡、四面出生和四分钟混合模拟。浏览器回归覆盖键鼠、触屏、升级暂停、三种镜头屏幕外提示、布局、模型资源及无外部请求。

参考对照测试推进分享页 revision 39 与本地自由飞行渲染器，在三种镜头各比较 456,036 个 RGBA 字节，差异均为 0，尾焰几何相同。空战规则、提示和 UI 属于新增内容。记录在 `artifacts/`。

浏览器测试需要 Playwright 和 Chrome，可用 `ISLAND_PLAYWRIGHT`、`ISLAND_BROWSER`、`ISLAND_URL` 指定。运行游戏本身没有这些依赖。

服务仅绑定本机 `127.0.0.1`。HTML / CSS / JS 可部署到普通静态网站服务器。`../versions/island-aces-v1.0.zip` 保留原版，v1.4 压缩包为当前版本；《黑洞》游戏位于上级目录，互相独立。
